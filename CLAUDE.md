# personal-dotcom

Personal website — Jekyll-based static site hosted on GitHub Pages.

## Stack

- Jekyll (Ruby)
- GitHub Pages
- SASS for styling

## Structure

- `_posts/` — blog posts
- `_layouts/` — page layouts
- `_includes/` — reusable HTML partials
- `_sass/` — SASS stylesheets
- `_config.yml` — Jekyll configuration
- `assets/` — static assets

## Branch

- Main branch is `gh-pages` (deployed via GitHub Pages)
